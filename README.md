# Go Finance Tracker

A simple CLI finance tracker written in Go.

This is a learning project for practicing Go data structures and building a small application for managing income and expenses.

## Learning Goals

- Arrays
- Slices
- Maps
- Functions
- Loops
- Conditionals
- Error handling

## Project Idea

The application will store financial transactions such as:

- Income
- Expenses

Example transactions:

```text
+5000
-1200
-350
+2000
